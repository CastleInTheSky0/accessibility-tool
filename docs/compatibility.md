# 兼容性与已知限制

## 目标浏览器

- 当前稳定版 Chrome
- 当前稳定版 Edge
- 当前稳定版 Firefox
- 当前稳定版 Safari

当前版本按桌面端 1024px 及以上设计。1024～1279px 使用紧凑单排布局，1280px 及以上的内部版心上限为 1280px；更窄视口不属于发布保证范围，也不提供移动端专用布局。

## 平台能力差异

- 音频朗读依赖浏览器 `speechSynthesis`。不支持时“朗读”和“声音开关”保持可聚焦并说明原因；大字幕仍可独立开启，“连续朗读”和“语速”会服务纯文字计时模式，但不会自动开启普通朗读状态或伪造语音事件。
- 连续朗读的暂停／继续不依赖浏览器全局 pause/resume：音频段暂停会取消当前段，继续时从该段开头重播；纯文字或音频失败回退段则冻结并恢复剩余展示时间，不保证从句中或词中恢复音频。
- 连续队列只遍历当前可见的普通 DOM、open Shadow Root、slot 和同源 iframe。closed Shadow Root 仍需由接入方提供已授权 root，跨域 iframe 永远不会被读取。
- 会话启动时冻结成员，因此无限滚动、直播区域和后续普通新增内容不会无限延长当前会话；删除、隐藏、忽略、敏感化或变空的已有成员会在朗读前或朗读中重新验证。
- 本地音色列表来自 `speechSynthesis.getVoices()`，不同浏览器、操作系统、语言包和用户安装状态会产生不同结果。浏览器可能先返回空数组，随后通过 `voiceschanged` 补充；工具会保持设置界面可用并刷新列表。
- 只显示并显式选择 `localService === true` 的音色。浏览器是否把某个系统音色标记为本地、默认音色名称及 `voiceURI` 的稳定性均由浏览器决定；不承诺跨浏览器或跨设备找到同一发音人。
- 自定义 `SpeechAdapter` 生效时，浏览器本地音色选择与试听不可用，但默认语言仍可作为页面内容语音请求的语言回退偏好。
- 自定义 `SpeechAdapter.speak()` 同步抛错会转换为一次有效 `error`；大字幕开启时当前段转为纯文字继续，无字幕回退时才结束连续会话。`cancel()` 同步抛错按最佳努力处理，不会阻断暂停、停止、路由或生命周期清理。
- 简繁转换与拼音由打入主 IIFE 的 `opencc-js` 和 `pinyin-pro` 在本地完成，不需要额外语言资源请求。标准简繁转换不包含台湾／香港地区词汇替换；拼音可有限利用上下文，但不承诺任意网页语境中的所有多音字都准确。
- 语言标签规范化优先依赖浏览器内置 `Intl`，不可用时退化为小型 BCP 47 基础规范化；检测失败仍会使用安全默认语言继续朗读。
- 全屏依赖标准 Fullscreen API，必须由用户手势触发，浏览器可能因权限策略拒绝。
- 跨域 iframe 受同源策略限制，工具不会尝试读取内部 DOM。
- 关闭式 Shadow Root 无法自动发现；接入方持有根节点时可通过 `regions.additionalRoots` 显式提供。
- 旧站 `aria-role` / `aria-readlabel` 只读兼容，但它们不是标准 ARIA，外部审计工具仍可能报告旧页面问题。

## 当前验证范围

- 自动化浏览器回归默认覆盖系统 Chrome 和 Edge。
- Firefox、Safari、NVDA 与 VoiceOver 仍需按人工测试清单完成发布前验证。
- 动态 DOM 更新使用约 120ms 的合并扫描；超大页面接入前应在真实页面上核对扫描耗时。
- 工具已打开后修改功能显隐或语音适配器，需要关闭并重新打开才能重建对应运行时控件。
- 自动语言检测只做本地 Unicode 脚本启发式判断。Latin 默认映射为 `en-US`；纯汉字日文、罗马字、多种 Latin 语言和无明显主导的混合文本需要页面显式 `lang` 或用户偏好。
- 不同浏览器和操作系统即使收到相同 `utterance.lang`，实际采用的本地音色、口音和回退结果仍可能不同。
- Chrome 与 Edge 自动化使用确定性的原生语音 fixture 覆盖初始空目录、`voiceschanged`、本地过滤、选择、试听、刷新恢复和原生对象替换；真实系统音质仍需人工验证。
- Chrome 与 Edge 自动化还覆盖连续朗读的共享会话、暂停重播、动态 DOM、路由、modal 边界、editable 隐私和零工具网络请求；Firefox、Safari 与真实系统语音仍按人工清单验证。
- Chrome 与 Edge 浏览器自动化覆盖大字幕双入口、独立单次文字输出、简繁／拼音、字号、持久化、长文本滚动、强制配色模拟和无额外语言资源请求；Vitest 运行时测试覆盖纯文字连续状态机、暂停／继续、音频启动前与中途错误回退和过期回调抑制。真实读屏、系统强制配色、200% 缩放、全屏保持与平台字体仍需按人工清单复核。

## v0.2 当前仍不包含

- 移动端或平板专用布局
- 第三方公开插件 API
- 云端 TTS 或后端服务
- 远程音色目录、厂商 SDK、密钥或网络音频
- 自动修复宿主页面全部无障碍问题
