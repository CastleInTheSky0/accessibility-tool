# 兼容性与已知限制

## 目标浏览器

- 当前稳定版 Chrome
- 当前稳定版 Edge
- 当前稳定版 Firefox
- 当前稳定版 Safari

首版按桌面端 1024px 及以上设计。更窄视口仍可横向滚动工具栏，但不提供移动端专用布局。

## 平台能力差异

- 朗读依赖浏览器 `speechSynthesis`。不支持时“朗读”“语速”“声音开关”保持可聚焦并说明原因。
- 全屏依赖标准 Fullscreen API，必须由用户手势触发，浏览器可能因权限策略拒绝。
- 跨域 iframe 受同源策略限制，工具不会尝试读取内部 DOM。
- 关闭式 Shadow Root 无法自动发现；接入方持有根节点时可通过 `regions.additionalRoots` 显式提供。
- 旧站 `aria-role` / `aria-readlabel` 只读兼容，但它们不是标准 ARIA，外部审计工具仍可能报告旧页面问题。

## 当前验证范围

- 自动化浏览器回归默认覆盖系统 Chrome 和 Edge。
- Firefox、Safari、NVDA 与 VoiceOver 仍需按人工测试清单完成发布前验证。
- 动态 DOM 更新使用约 120ms 的合并扫描；超大页面接入前应在真实页面上核对扫描耗时。
- 工具已打开后修改功能显隐或语音适配器，需要关闭并重新打开才能重建对应运行时控件。

## v0.1.0 不包含

- 连续朗读
- 大字幕
- 移动端或平板专用布局
- 用户音色 / 发音人选择
- 自动语言检测
- 第三方公开插件 API
- 云端 TTS 或后端服务
- 自动修复宿主页面全部无障碍问题
