# 人工无障碍测试清单

自动化不能替代真实读屏和浏览器测试。发布前至少完成以下检查。

## Windows：Chrome / Edge / Firefox + NVDA

- [ ] 清除打开意图后首次加载页面，脚本不移动焦点、不发声、不出现工具栏，也不启动页面扫描和高频监听。
- [ ] 唤醒按钮打开工具后，NVDA 读出工具栏已打开和方向键提示。
- [ ] 成功打开后刷新页面，工具在 DOM ready 后自动恢复完整功能，但保持页面原焦点且不再次读出“工具栏已打开”。
- [ ] 从已打开页面进入另一个同源且引入相同脚本的页面，工具继续保持打开并应用已存偏好。
- [ ] 调用 `close()`、选择“退出”或调用 `destroy()` 后刷新，工具保持关闭；`reset()` 后刷新仍自动恢复打开。
- [ ] `persistOpenState: false` 会清理当前打开标记；损坏或被阻止的 localStorage 不抛错，并退化为无跨刷新恢复。
- [ ] 左右方向键、Home、End、Enter、空格与 Tab 行为正确。
- [ ] 工具打开时，Tab、Shift + Tab、鼠标和脚本聚焦的真实页面节点显示黄色 `#ffb800` 轮廓；工具栏内部不重复显示页面轮廓。
- [ ] 普通 Tab 先到达盲道区域容器；区域自身只显示黄色轮廓，进入子节点后外层区域显示深橙色 `#ff6c00`、当前子节点显示黄色，离开区域后活动轮廓消失。
- [ ] 页面原有蓝色 focus outline 不与黄色轮廓重叠，退出后原 outline 值和 `!important` 优先级完整恢复。
- [ ] 所有按钮同时有可理解的文字和状态，开关读出“按下/未按下”。
- [ ] 输入框、文本域、`role="textbox"` 和可编辑输入区域使用“输入框：内容”朗读；占位提示示例为“输入框：请输入关键词”。
- [ ] 不支持功能仍可聚焦，并读出不可用原因。
- [ ] 点击“语速”或在该按钮上按 Enter / 空格会依次循环 0.75×、1×、1.25×、1.5× 并回到 0.75×；不会打开弹窗，当前值、图标、播报和持久化同步更新。
- [ ] 五种配色、75%～200% 缩放、大鼠标和十字线可独立开关。
- [ ] 大界面成功后读出“按 Esc 退出”，第一次 Esc 只退出浏览器全屏。
- [ ] 固定后鼠标离开工具栏立即开始约 180ms 的收起动画；纯键盘 focusout 才按约 1.5 秒的配置延迟收起，Alt + Shift + A 可重新展开。
- [ ] 读屏专用显示六类实时数量，零数量项置灰且方向键跳过。
- [ ] Alt + Shift + 1～6 在页面内容中工作，在输入框中不拦截。
- [ ] 同类多个区域按 DOM 顺序循环，每类独立记忆位置。
- [ ] 未显式标记的原生 `main` 不计入正文区；显式区域、`article` 和 `role="main"` 仍可正常识别。
- [ ] 动态删除当前区域后移动到下一个同类区域或返回分类按钮。
- [ ] 标准选项卡的每个有效选项都在原生 Tab 顺序中，Tab/Shift + Tab 可逐项进入并自然离开。
- [ ] 同一 tablist 中不同选项可分别声明自动/手动模式和触发事件；父级 tablist 上的旧行为属性不生效，配置与 `click` 回退正确。
- [ ] 普通关联面板和非原生浮层由页面原事件切换 `data-a11y-hidden`，不会产生宿主 `[role="tabpanel"][hidden]`；同时检查工具正确同步 `aria-hidden`。
- [ ] 首次键盘进入每组选项卡时只提示一次关联面板快捷键。
- [ ] Alt + 下方向键进入面板；面板内 Esc 返回原选项。
- [ ] 模态浮层 Tab 循环，非模态浮层允许焦点离开。
- [ ] 退出后焦点回到最近唤醒按钮，所有页面效果恢复。
- [ ] 重置保持工具栏打开并聚焦“重置”。

## macOS：Safari + VoiceOver

- [ ] 使用 Control + Option 导航时工具栏语义和按钮名称正确。
- [ ] Shadow DOM 内工具栏可以完整访问。
- [ ] 标准全屏进入和退出提示正确。
- [ ] 语音合成支持检测正确；浏览器拒绝时给出明确提示。
- [ ] 开放式 Shadow Root 和同源 iframe 区域可识别。
- [ ] 帮助链接在新标签页打开且不会劫持原页面焦点。

## 视觉与高对比

- [ ] 1024px 宽度下主模式与读屏专用模式均保持单行，无横向滚动、裁切或功能丢失。
- [ ] 200% 浏览器缩放下文字不截断、焦点环不被裁切。
- [ ] `prefers-reduced-motion: reduce` 下无平滑动画依赖。
- [ ] Windows 强制配色下系统颜色优先，按钮和焦点仍可辨认。
- [ ] 强宿主 CSS 页面不改变工具栏按钮、SVG、排版和焦点样式。
