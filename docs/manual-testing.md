# 人工无障碍测试清单

自动化不能替代真实读屏和浏览器测试。发布前至少完成以下检查。

## Windows：Chrome / Edge / Firefox + NVDA

- [ ] 脚本加载后不自动移动焦点、发声或出现工具栏。
- [ ] 唤醒按钮打开工具后，NVDA 读出工具栏已打开和方向键提示。
- [ ] 左右方向键、Home、End、Enter、空格与 Tab 行为正确。
- [ ] 所有按钮同时有可理解的文字和状态，开关读出“按下/未按下”。
- [ ] 不支持功能仍可聚焦，并读出不可用原因。
- [ ] 语速面板的四个预设、滑块值和 Esc 返回正确。
- [ ] 五种配色、75%～200% 缩放、大鼠标和十字线可独立开关。
- [ ] 大界面成功后读出“按 Esc 退出”，第一次 Esc 只退出浏览器全屏。
- [ ] 固定后离开工具栏约 1.5 秒收起；Alt + Shift + A 可重新展开。
- [ ] 读屏专用显示六类实时数量，零数量项置灰且方向键跳过。
- [ ] Alt + Shift + 1～6 在页面内容中工作，在输入框中不拦截。
- [ ] 同类多个区域按 DOM 顺序循环，每类独立记忆位置。
- [ ] 动态删除当前区域后移动到下一个同类区域或返回分类按钮。
- [ ] 标准选项卡只占一个 Tab 停靠点，自动与手动模式均正确。
- [ ] 首次键盘进入每组选项卡时只提示一次关联面板快捷键。
- [ ] Alt + 下方向键进入面板；面板内 Esc 返回原选项。
- [ ] 模态浮层 Tab 循环，非模态浮层允许焦点离开。
- [ ] 退出后焦点回到最近唤醒按钮，所有页面效果恢复。
- [ ] 重置保持工具栏打开并聚焦“重置”。

## macOS：Safari + VoiceOver

- [ ] 使用 Control + Option 导航时工具栏语义和按钮名称正确。
- [ ] Shadow DOM 内工具栏可以完整访问。
- [ ] 标准全屏进入和退出提示正确。
- [ ] 语音合成支持检测正确；浏览器拒绝时给出明确提示。
- [ ] 开放式 Shadow Root 和同源 iframe 区域可识别。
- [ ] 帮助链接在新标签页打开且不会劫持原页面焦点。

## 视觉与高对比

- [ ] 1024px 宽度下所有功能可通过内部横向滚动访问。
- [ ] 200% 浏览器缩放下文字不截断、焦点环不被裁切。
- [ ] `prefers-reduced-motion: reduce` 下无平滑动画依赖。
- [ ] Windows 强制配色下系统颜色优先，按钮和焦点仍可辨认。
- [ ] 强宿主 CSS 页面不改变工具栏按钮、SVG、排版和焦点样式。
