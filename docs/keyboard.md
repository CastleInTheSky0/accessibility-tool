# 键盘与快捷键

## 工具栏

| 按键 | 行为 |
| --- | --- |
| 左 / 右方向键 | 在当前工具栏功能间移动 |
| Home / End | 移到首项 / 末项 |
| Enter / 空格 | 执行当前功能；聚焦“语速”时依次循环 0.75×、1×、1.25×、1.5× |
| Tab | 离开工具栏 |
| Alt + Shift + A | 展开已固定并收起的工具栏 |

工具打开期间，页面内容中的当前真实焦点节点会显示黄色 `#ffb800` 轮廓。Tab、Shift + Tab、鼠标点击、脚本聚焦和盲道区域定位都使用同一提示；工具栏内部控件继续使用自身焦点样式。工具会临时接管节点原有 outline，并在焦点切换、关闭或销毁时精确恢复原值与 `!important` 优先级。

每个可见盲道区域容器会临时进入原生 Tab 顺序。区域容器自身获得焦点时只显示黄色轮廓；按 Tab 进入可聚焦子节点后，外层区域显示深橙色 `#ff6c00` 轮廓，当前子节点显示黄色轮廓。Tab 与 Shift + Tab 始终沿浏览器原生 DOM 顺序移动，不改写后代节点的 `tabindex`，也不限制焦点离开区域。

不受浏览器支持的功能仍可聚焦，并通过 `aria-disabled="true"` 说明原因。

## 读屏专用

只在读屏专用模式开启时生效：

| 快捷键 | 区域 |
| --- | --- |
| Alt + Shift + 1 | 视窗区 |
| Alt + Shift + 2 | 导航区 |
| Alt + Shift + 3 | 交互区 |
| Alt + Shift + 4 | 服务区 |
| Alt + Shift + 5 | 列表区 |
| Alt + Shift + 6 | 正文区 |

输入框、文本域、下拉框、`contenteditable` 和 `role="textbox"` 内不会拦截这些快捷键。

## 标准选项卡

| 按键 | 行为 |
| --- | --- |
| 左 / 右方向键 | 横向 tablist 中移动 |
| 上 / 下方向键 | 纵向 tablist 中移动 |
| Home / End | 移到首项 / 末项 |
| Enter / 空格 | 手动激活模式下触发原页面事件 |
| Alt + 下方向键 | 等待关联面板显示后进入面板 |
| Esc | 从面板或浮层返回原选项 |

每个有效 `role="tab"` 选项都是独立的 Tab 停靠点。自动或手动激活模式由当前对应选项决定：Tab 和方向键移动时读取目标选项，Enter 或空格读取当前选项。

浏览器处于全屏时，第一次 Esc 优先交给浏览器退出全屏。
