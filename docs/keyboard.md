# 键盘与快捷键

## 工具栏

| 按键 | 行为 |
| --- | --- |
| 左 / 右方向键 | 在当前工具栏功能间移动 |
| Home / End | 移到首项 / 末项 |
| Enter / 空格 | 执行当前功能 |
| Tab | 离开工具栏 |
| Esc | 关闭语速面板并返回“语速”按钮 |
| Alt + Shift + A | 展开已固定并收起的工具栏 |

工具打开期间，页面内容中的当前焦点会显示独立的橙色高亮框。Tab、Shift + Tab、鼠标点击、脚本聚焦和盲道区域定位都使用同一提示；工具栏内部控件继续使用自身焦点样式。工具会在页面焦点视觉提示接管呈现时临时隐藏页面原有 outline，并在焦点切换、关闭或销毁时恢复原值。

选择盲道区域后，区域容器使用青色、黑色和白色组成的高对比上下文框。容器首次聚焦时只显示区域框；按 Tab 进入可聚焦子节点后，区域框保持不动，橙色框跟随当前子节点。Tab 与 Shift + Tab 始终沿浏览器原生 DOM 顺序移动，不增加子节点 `tabindex`，也不限制焦点离开区域。

不受浏览器支持的功能仍可聚焦，并通过 `aria-disabled="true"` 说明原因。

## 读屏专用

只在读屏专用模式开启时生效：

| 快捷键 | 区域 |
| --- | --- |
| Alt + Shift + 1 | 视窗区 |
| Alt + Shift + 2 | 导航区 |
| Alt + Shift + 3 | 交互区 |
| Alt + Shift + 4 | 服务区 |
| Alt + Shift + 5 | 列表区 |
| Alt + Shift + 6 | 正文区 |

输入框、文本域、下拉框、`contenteditable` 和 `role="textbox"` 内不会拦截这些快捷键。

## 标准选项卡

| 按键 | 行为 |
| --- | --- |
| 左 / 右方向键 | 横向 tablist 中移动 |
| 上 / 下方向键 | 纵向 tablist 中移动 |
| Home / End | 移到首项 / 末项 |
| Enter / 空格 | 手动激活模式下触发原页面事件 |
| Alt + 下方向键 | 等待关联面板显示后进入面板 |
| Esc | 从面板或浮层返回原选项 |

浏览器处于全屏时，第一次 Esc 优先交给浏览器退出全屏。
