# 大字幕

## Goal

同步展示当前有效朗读文本，为听力、认知和环境受限用户提供清晰、高对比、可关闭且不会造成屏幕阅读器双重播报的视觉字幕。

## Scope

- 字幕显示、关闭和重新打开入口。
- 与 `speechstart`、`speechend`、取消和错误同步。
- 连续朗读中按当前有效段落更新。
- 明确字号、行高、高对比、长文本换行／滚动和屏幕边缘安全距离。
- 完整键盘操作和屏幕阅读器语义。
- 定义是否允许拖动、调整位置或仅使用预设位置。
- `close()`、`destroy()` 和过期语音请求时清理。
- 定义桌面、手机和平板的展示差异，但移动／平板生产布局仍受各自设计门禁控制。

## Non-goals

- 字幕自身触发语音、使用 `aria-live` 重复朗读当前文本。
- 语音识别、自动翻译、逐词时间轴或视频字幕文件。
- 在移动／平板设计确认前实现其正式响应式布局。

## Technical Approach

- 字幕只订阅现有有效语音请求／连续阅读状态，不建立第二套播放状态。
- 当前文本容器默认不使用会重复播报的 live region；控制状态另用简短可访问名称反馈。
- 使用 Shadow DOM 内独立可清理的 overlay，与阅读高亮和区域焦点所有权分离。
- 长文本采用有界高度、自然换行和用户可控滚动。

## Acceptance Criteria

- [ ] 单次和连续朗读均显示当前有效文本。
- [ ] end、cancel、error、close、destroy 后字幕按规则隐藏或清空。
- [ ] 旧请求回调不能覆盖新字幕。
- [ ] 长文本可读、可滚动且不遮挡关键控制。
- [ ] 键盘可打开、关闭和操作滚动区域。
- [ ] 屏幕阅读器不会因字幕文本产生第二次完整播报。
- [ ] 强制配色、深色和既有五种配色下均可辨认。

## Definition of Done

- 生命周期、视觉、键盘、读屏和长文本均有自动化与人工覆盖。
- 与连续朗读共享唯一当前段落来源。
- 桌面实现稳定；移动／平板差异留给已确认设计实现。

## Unit Test Plan

- speech start/end/cancel/error、连续段更新和过期事件。
- 开关状态、清理、文本更新、滚动状态和无 live 重复语义。

## E2E Test Plan

- Chrome／Edge 覆盖单次、连续、取消、错误、长文本和键盘。
- forced-colors、缩放 200%、窄视口设计 fixture（仅验证设计约束，不提前实现移动布局）。
- axe 检查无新增严重／关键问题。

## Documentation Update Plan

- 更新 README、API、键盘、兼容性、人工测试和运行时 contract。

## Open Decisions for This Task

- 字幕默认位置、最大高度和是否允许拖动。
- 结束后立即隐藏、短暂保留还是保留至下一段。
- 字幕开关是否进入主工具栏，如何保持单行桌面契约。

## Design/Implementation Gate

本任务在连续朗读完成并归档后再细化完整 PRD；PRD 获确认前不实现生产代码。
