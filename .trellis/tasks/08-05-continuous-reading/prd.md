# 连续朗读

## Goal

在现有 `SpeechController`、`BrowserSpeechAdapter`、区域扫描、焦点、tabs 和取消机制之上增加可控、可恢复、不会播报过期内容的页面连续阅读流程。

## Scope

- 定义从当前焦点／当前区域／页面起点开始朗读的规则。
- 使用可预测的 DOM 阅读顺序在区域和内容之间衔接。
- 支持开始、暂停、继续、停止。
- 明确用户移动焦点、点击其他朗读目标和手动区域导航后的行为。
- 处理动态 DOM 新增、删除、隐藏、弹窗、表单控件和 SPA 路由变化。
- `close()`、`destroy()` 和新请求使旧队列、旧回调和过期内容失效。
- 为大字幕提供当前有效段落和生命周期边界。

## Non-goals

- 云端流式音频、服务端分段、后端播放列表和远程正文缓存。
- 在同一文本内部做逐词语言／音色切换。
- 自动朗读密码、验证码、支付或 `data-a11y-sensitive` 内容。

## Technical Approach

- 扩展现有 Reading/Speech 控制器，不创建平行 adapter 或播放系统。
- 从 `RegionScanner` 的 roots 和现有可读目标规则生成惰性阅读序列。
- 每个序列和段落拥有请求代次；DOM 与路由变化时重新验证当前节点。
- 暂停／继续优先使用可预测的队列状态，不依赖浏览器跨平台不一致的全局 pause 状态而失去控制。
- 复用语言解析和本地音色选择，每段在请求前重新解析。

## Acceptance Criteria

- [ ] 起点、阅读顺序和区域衔接与 PRD 最终规则一致。
- [ ] 开始、暂停、继续、停止均可键盘操作并有明确状态。
- [ ] 焦点移动、点击其他目标和区域导航不会形成双重播报。
- [ ] 删除／隐藏当前节点后安全前进或停止，不朗读断开 DOM。
- [ ] 弹窗和 tabs 只朗读当前有效可见上下文。
- [ ] SPA 路由、`close()`、`destroy()` 和较新请求让旧内容失效。
- [ ] 对外事件可区分连续阅读开始、段落变化、暂停、继续和停止。
- [ ] 大字幕能消费当前有效段落，不建立第二套状态。

## Definition of Done

- 状态机、序列、取消、动态 DOM、路由和生命周期均有单元与 E2E 覆盖。
- 现有单次焦点／悬停／点击朗读和公共 API 向后兼容。
- 无敏感内容泄露，无网络或后端依赖。

## Unit Test Plan

- 起点和 DOM 顺序、区域衔接、隐藏／忽略／敏感节点过滤。
- 开始、暂停、继续、停止状态转换和幂等。
- 焦点／点击抢占、动态删除、路由、close/destroy、过期回调。
- 多语言段落与音色回退。

## E2E Test Plan

- Chrome／Edge 覆盖页面起点、当前焦点、跨区域、tabs、表单和弹窗。
- 动态新增／删除／隐藏节点与 SPA 导航。
- 键盘全流程和工具栏状态同步。
- 使用确定性 adapter 验证实际请求顺序和旧请求失效。

## Documentation Update Plan

- 更新 README、API、键盘、兼容性、人工测试和运行时 contract。

## Open Decisions for This Task

- 默认起点优先当前页面焦点、当前盲道区域还是第一个可读节点。
- 暂停后用户主动聚焦其他目标时是停止队列还是更新恢复点。
- 弹窗打开时是挂起背景队列还是直接重建为弹窗上下文。

## Design/Implementation Gate

本任务在音色选择完成并归档后再细化完整 PRD；PRD 获确认前不实现生产代码。
