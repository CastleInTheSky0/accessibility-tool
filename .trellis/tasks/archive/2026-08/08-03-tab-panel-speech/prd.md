# 优化选项卡与关联面板朗读提示

## Goal

将选项获得焦点、进入关联面板和按 Esc 返回的朗读整理为一套单次、完整且上下文明确的中文提示，使用户同时知道当前是选项卡、选项名称、所在盲道区域、是否为链接以及进入/退出面板的键盘操作。

## What I already know

- 当前普通朗读会把 `role="tab"` 当作普通内容，通常读成 `文本：{选项名称}，已选中/未选中`。
- 当前 `TabsController` 只在键盘首次进入一个选项卡组时额外提示“有关联内容面板，按 Alt+下方向键进入”，因此会与普通朗读分成两条，且后续选项不再提供完整操作提示。
- `Alt+下方向键` 已负责打开/进入 `aria-controls` 关联面板，面板内 `Esc` 已负责返回原选项；本任务只优化朗读与必要的去重协调，不改变快捷键。
- 标准选项与面板关系仍由 `role="tablist"`、`role="tab"`、`aria-controls`、面板 ID 和 `role="tabpanel"` 建立。
- 用户要求选项描述包含：Tab 标签语义、选项名称、所在盲道区域名称、进入面板的操作方式。
- 若选项本身是带 `href` 的链接，整条选项描述最前面增加 `链接：{文案}`。
- 用户要求进入面板时在“标签面板”前同时包含来源选项名称和盲道区域分类名称。
- `public/index.html` 和两个 logo 是用户已有工作区改动，本任务不得覆盖或纳入。

## Confirmed behavior

- 选项名称沿用已确认的名称优先级：工具专用/ARIA 名称 → `aria-labelledby` → `title` → 可见文本。
- 每次通过 Tab、Shift+Tab、方向键、点击后聚焦或脚本聚焦切换到有效 `role="tab"`，都应得到一条合并后的完整描述；Esc 返回是唯一例外，使用下述简短提示。
- 面板进入提示使用来源选项名称，而不是直接朗读面板全部文本。
- 选项焦点提示与面板进入提示都必须避免被普通 `ReadingController` 的 `文本：...` 朗读覆盖。
- Esc 返回原选项时不重复完整选项说明，只朗读简短提示：`已返回{选项名称}选项`。

## Requirements

- 有效选项获得焦点时只产生一条完整提示，不再先读普通文本、再读面板操作提示。
- 非链接选项的完整格式固定为：`Tab，{选项名称}，{盲道区域分类名称}，当前有浮动窗口，按 ALT+下键进入窗口`。
- 选项完整提示不追加 `已选中/未选中` 等状态，避免偏离用户确认的固定文案。
- 盲道区域部分只使用六类分类名称之一：`视窗区`、`导航区`、`交互区`、`服务区`、`列表区`、`正文区`；不拼接区域短名称。
- 选项不位于任何已识别区域时，省略区域分类及对应分隔符：非链接选项为 `Tab，{选项名称}，当前有浮动窗口，按 ALT+下键进入窗口`；链接选项为 `链接：{选项名称}，Tab，当前有浮动窗口，按 ALT+下键进入窗口`。
- 链接选项的完整格式固定为：`链接：{选项名称}，Tab，{盲道区域分类名称}，当前有浮动窗口，按 ALT+下键进入窗口`；选项名称只出现一次。
- 进入面板后只朗读一次：`您已进入{选项名称}{盲道区域分类名称}标签面板，按 Tab 键遍历信息，按 Esc 键退出面板并返回{选项名称}选项`。
- 来源选项没有所在区域时，面板提示省略分类名称，使用 `您已进入{选项名称}标签面板...`。
- 若面板没有任何可通过 Tab 聚焦的后代，进入提示自适应为：`您已进入{选项名称}{盲道区域分类名称}标签面板，当前面板暂无可通过 Tab 遍历的信息，按 Esc 键退出面板并返回{选项名称}选项`；不得为了满足提示而给静态内容增加 Tab 焦点。
- 面板内部节点继续按当前链接、图片、按钮、表单和 `文本：` 规则朗读。
- Esc 成功退出面板并将焦点返回来源选项后，只朗读一次 `已返回{选项名称}选项`；不得同时触发普通文本朗读或完整选项提示。
- 若面板无法关闭或焦点没有成功返回，则不得虚假朗读“已返回”。
- 缺少有效关联面板的选项卡组继续沿用现有校验与错误行为，不拼接虚假的面板操作提示。

## Acceptance Criteria

- [x] 每个有效选项通过 Tab、Shift+Tab、方向键或脚本聚焦时都只朗读一条完整选项描述。
- [x] 非链接选项逐字遵循 `Tab，{选项名称}，{盲道区域分类名称}，当前有浮动窗口，按 ALT+下键进入窗口`，不追加选择状态。
- [x] 链接选项逐字遵循 `链接：{选项名称}，Tab，{盲道区域分类名称}，当前有浮动窗口，按 ALT+下键进入窗口`，且名称只出现一次。
- [x] 选项提示只包含所在盲道区域分类名称，不包含区域短名称；无所在区域时使用确认后的回退行为。
- [x] 无所在区域时自然省略分类片段，不朗读“未知区域”或留下重复标点。
- [x] Alt+下方向键进入面板后只朗读一次 `您已进入{选项名称}{盲道区域分类名称}标签面板，按 Tab 键遍历信息，按 Esc 键退出面板并返回{选项名称}选项`，不朗读整块面板内容。
- [x] 面板无可聚焦后代时使用“暂无可通过 Tab 遍历的信息”版本，且不改变页面原有焦点顺序。
- [x] 面板内部 Tab 遍历保持浏览器原顺序；Esc 成功返回后只朗读一次 `已返回{选项名称}选项`。
- [x] Esc 返回时不重复完整选项提示，也不出现 `文本：...` 等第二条语音；返回失败时不朗读成功提示。
- [x] 监听器注册顺序不会导致重复或覆盖朗读。
- [x] open Shadow Root、同源 iframe、普通面板和 dialog 保持现有支持。
- [x] `pnpm typecheck`、`pnpm lint`、`pnpm test`、`pnpm build` 通过，并按风险执行相关 E2E。

- 补充精确单元测试和相关键盘 E2E。
- 同步帮助、属性文档和前端行为契约。
- 不包含用户现有演示页和 logo 改动。

## Out of Scope

- 修改选项卡激活模式、宿主事件、面板显隐协议或快捷键。
- 改变普通页面节点和盲道区域进入提示的既有朗读格式。
- 实现完整桌面读屏软件措辞。
- 新增公开配置项、主题能力或通用朗读模板系统。
- 为静态面板内容补充 `tabindex`，或改变面板内部原有 Tab 顺序。

## Expansion Sweep

- **未来演进**：保留集中生成选项/面板提示的内部边界，后续可扩展国际化或可配置措辞；首版不新增相关公开 API。
- **相关场景**：普通 DOM、open Shadow Root、同源 iframe 和 dialog 继续共用现有扫描与焦点流程，不另建一套选项卡协议。
- **失败与边界**：覆盖无所属区域、链接选项、无可聚焦后代、无有效面板、面板打开超时、面板关闭失败和监听器注册顺序差异。
- **MVP 结论**：遵循用户“不要扩大范围”的要求，只实现本 PRD 已确认的朗读与去重行为。

## Technical Approach

- 将有效 `role="tab"`、面板入口和 Esc 返回视为专用焦点朗读场景，由一个明确的单次覆盖/协调通道生成语音，普通 `ReadingController` 不再对同一次焦点事件追加 `文本：...`。
- 选项提示每次按当前节点动态生成；不再依赖 `TabGroup.announced` 的“组内首次提示”状态。
- 在 `Alt+下方向键` 聚焦面板前登记一次性面板进入提示；在 Esc 确认关闭成功并准备聚焦来源选项前登记一次性返回提示。提示应与目标焦点绑定，避免异步显示或失败路径误报。
- 通过当前扫描结果中的 `ScannedRegion.type` 查找目标所在的最内层有效区域，并映射为六类固定中文分类名称；沿用 composed tree 判断以覆盖 open Shadow Root 和同源 iframe。
- 选项名称沿用现有可访问名称解析；链接判断以选项节点自身是否为带有效 `href` 的 `a` 元素为准。
- 使用纯函数集中拼装三类文案（选项、进入面板、返回选项），以逐字断言单元测试；用键盘 E2E 验证真实焦点、面板遍历和 Esc 返回。

## Decision (ADR-lite)

**Context**：现有 `ReadingController` 与 `TabsController` 都会对选项焦点发起朗读，导致分成两条、顺序依赖和重复；面板进入与返回也缺少完整上下文。

**Decision**：采用“专用场景单次覆盖”的协调方式，把一次焦点变化收敛成一条确定文案；区域分类取自真实扫描结果，Esc 返回采用简短提示 `已返回{选项名称}选项`。

**Consequences**：朗读结果不再依赖监听器注册顺序，文案可精确测试；实现需要在 Tabs、Reading、区域查找和工具装配之间增加一个很小的内部协作边界，但不新增公开 API，也不改变现有键盘与面板协议。

## Implementation Plan

1. 增加选项、面板入口和返回提示的纯文案生成及区域分类解析，并补充单元测试。
2. 接入 Tabs/Reading 的单次朗读协调，移除组级首次提示，处理进入、失败与 Esc 返回路径。
3. 补充普通 DOM、Shadow Root、同源 iframe、链接选项、空面板与监听顺序相关测试，并同步帮助/行为契约文档。

## Technical Notes

- 主要文件：`src/features/tabs.ts`、`src/features/reading.ts`、`src/features/region-navigation.ts`、`src/core/dom.ts`、`src/tool.ts`。
- 现有 `TabGroup.announced` 只支持组级首次提示，新方案更适合基于当前选项生成每次焦点的完整描述。
- 区域分类名称应来自扫描后的真实 `ScannedRegion.type` 并映射到六类固定名称，不能只靠 DOM 属性猜测，以覆盖语义自动识别、Shadow Root 和同源 iframe。
- 选项与面板必须提供“精确容器判断/朗读覆盖”能力，使普通 Reading 监听器无论先后注册都不会产生第二条语音。
