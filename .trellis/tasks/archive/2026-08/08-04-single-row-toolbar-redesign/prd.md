# 重构单层盲道轨迹工具栏 UI

## Goal

将当前由浅色方块按钮组成的工具栏重构为具有独立产品识别度的“盲道轨迹”单层工具栏：使用深色一体化表面、连续轨道、状态节点和克制的状态高亮，在 1200px 桌面宽度下保持舒适尺寸，同时保留现有功能、顺序、键盘模型、页面占位和 Shadow DOM 隔离。

## Visual Thesis

以盲道连续轨迹作为视觉母题：石墨黑一体化工具栏承载一条低对比轨道，功能图标、文字与状态节点依次落在轨道上；橙色只表示已开启或当前模式，红色只表示退出，常态不再出现浅色卡片阵列。

## Content Plan

- 左侧为非交互品牌轨道：主模式显示 `A11Y / 辅助工具`，盲道导航模式显示 `盲道导航`。
- 主模式保持现有固定顺序：朗读、语速、配色、放大、缩小、大鼠标、十字线、大界面、固定、重置、帮助、读屏专用、退出。
- 盲道导航模式固定顺序：视窗区、导航区、交互区、服务区、列表区、正文区、朗读、帮助、读屏专用、退出。
- 每个功能继续显示现有图标、名称和状态元信息；不显示“阅读、视觉辅助、工具、模式”等额外分组文字。

## Interaction Thesis

- 模式切换只替换内部内容，主模式和盲道导航模式使用完全相同的固定高度，页面预留空间不发生跳变。
- 开启态在状态提交后立即使用与“固定”一致的深橙表面、橙色图标容器和橙色轨道节点；退出使用深红表面和红色图标容器。
- 常态不显示黄色边框；真实键盘 `:focus-visible` 使用独立的高对比焦点样式，不与橙色开启态混淆。

## Requirements

- 工具栏改为单层轨迹布局，不得换成双层，也不得恢复整块浅色卡片按钮。
- 主工具栏与盲道导航工具栏外层高度必须一致；切换 `isReadScreen` 不得改变 Shadow Host 高度、正文占位或配置的 offsetSelectors 偏移。
- 完整视觉设计以 1200px 及以上桌面宽度为验收基准：单项宽度约 80–84px、图标容器约 36–38px、工具栏高度约 144–146px。
- 外层 Shadow Host/工具栏背景继续铺满视口宽度；品牌轨道、当前模式控件和连续轨迹线必须作为一个整体放在最大宽度 `1200px` 的居中版心中，不得把控件平均拉伸到整个宽屏视口。
- 视口宽于 1200px 时，版心外只显示左右深色背景留白：1440px 约各 120px，1600px 约各 200px；主模式和盲道导航模式必须共享同一版心边界。
- 1024–1199px 继续保持功能可用和单行顺序，可使用较紧凑的宽度回退，但不得影响键盘导航、按钮可访问名称或页面关闭/恢复。
- 左侧品牌轨道不参与 Tab 顺序，不增加工具栏可访问项，也不改变现有 roving tabindex 模型。
- 工具栏主体使用连续低对比轨道；每个控制提供节点，开启态节点变为橙色并放大，退出节点为红色。
- 不显示“阅读、视觉辅助、工具、模式”等分组名称；可保留少量无文本的双点分隔标记。
- 默认控制为透明/深色表面，不使用当前 `--a11y-control-bg` 的大面积浅色卡片；悬停仅使用克制的深色提亮。
- 所有 `aria-pressed="true"` 二态控制使用与“固定”相同的深橙高亮规则；图标仍根据真实状态切换。
- 标准模式中每个 `aria-pressed="true"` 的二态功能在保留现有深橙卡片与图标状态的同时，其轨迹节点增加“橙色实心节点 + 背景间隔 + 橙色外环”，节点附近的独立橙色短轨迹从中心 `scaleX(0→1)` 展开，关闭时 `scaleX(1→0)` 收回。
- 标准模式允许多个二态功能同时开启并各自显示局部高亮；语速、配色、放大、缩小、重置、帮助等非二态功能不得误显示，退出继续使用红色节点和危险色表面且不得套用橙色局部轨迹动画。
- 退出控制始终使用危险色视觉语言，并继续保留现有行为。
- 语速按钮常态不显示黄色边框；键盘焦点仅在真实 `:focus-visible` 时出现，推荐使用白色高对比轮廓并与橙色开启态保持可区分。
- “语速”是直接执行的单一按钮，不再打开弹窗：点击或按 Enter / 空格时按 `[0.75, 1, 1.25, 1.5]` 循环。当前值命中预设时取下一档，`1.5` 后回到 `0.75`；配置或持久化值不在预设中时取第一个严格大于当前值的预设，无更大值则回到 `0.75`。
- 每次语速切换必须保持焦点在原按钮，同步状态、偏好持久化、图标、元信息和 aria-label，并 announce / 在朗读开启时播报“当前语速 X 倍”。“朗读”按钮仍只控制朗读开关，语速按钮不得改变朗读开关状态。
- 完全删除语速 dialog、预设按钮、滑块、输出值、打开/关闭方法及 `aria-haspopup`、`aria-expanded`、`aria-controls` 弹窗语义；语速不得再作为固定工具栏收起的阻止条件。
- 盲道导航模式中的 `screenSound` 可访问动作不变，但可见文案与 aria-label 统一为“朗读”，状态元信息显示开启/关闭。
- 盲道导航模式必须继续显示 `readScreen` 控制，位于帮助之后、退出之前；当前处于盲道导航模式时使用与固定按钮相同的开启高亮。
- 六类区域控制继续使用真实区域数量和现有禁用规则；数量为 0 的区域仍保持现有跳过键盘导航语义。
- 成功定位或通过页面焦点进入某个已识别区域后，对应类别控制成为唯一“当前区域”；同类循环时状态保留在该类别并更新当前序号，跨类别定位时状态随之移动。失败定位不得制造当前态。
- 当前区域只使用区域节点与节点附近的一段橙色轨迹表达，不使用主功能 `aria-pressed` 开启态的卡片背景；键盘 `:focus-visible` 继续使用独立的高对比轮廓，与当前区域橙色状态保持可区分。
- 当前区域节点必须同时显示橙色实心节点、与工具栏背景同色的间隔和橙色外环，匹配批准稿的双层节点；该橙色外环表达当前位置，不得复用或替代键盘 `:focus-visible` 的白色高对比焦点环。
- 每个区域控制的局部橙色轨迹伪元素始终存在，默认以节点中心为原点收缩为 `scaleX(0)`，成为当前区域时展开为 `scaleX(1)`；切换类别时旧轨迹向中心收起、新轨迹同时从中心向两侧展开，清除当前态时同样收起，不增加 JS 定时器或离场状态。
- 当前节点背景、外环和局部轨迹使用约 `180–240ms` 的克制缓动过渡；`prefers-reduced-motion: reduce` 下立即切换，不播放任何当前区域节点或轨迹动画。
- 当前区域计数显示为 `当前序号/总数`，其中区域事件的 0-based `index` 在界面显示为 `index + 1`；未选中类别仍只显示总数。区域按钮继续保留原有 aria-label、roving tabindex、朗读和导航行为。
- 点击区域按钮、区域快捷键以及页面焦点进入区域所产生的既有 `regionchange` 路径必须驱动同一视觉状态。当前区域被清除、失效、工具关闭或焦点按既有逻辑返回工具栏时，不得残留错误高亮。
- 区域当前位置使用 `aria-current="location"` 与稳定的数据状态属性表达，不得将区域导航错误建模为 `aria-pressed` 可切换开关；任一时刻最多一个区域控制具有当前位置状态。
- 工具开启后，普通 Tab 顺序必须先停在已识别的盲道区域容器，再由浏览器按原生 DOM 顺序进入该区域内已有的可聚焦节点；不得拦截 Tab、制造静态正文焦点或重排区域内部节点。
- 区域容器自身获得焦点时只显示当前焦点框；焦点进入区域内部节点后，外层区域必须持续显示独立的高对比度橙色 `#ff6c00` 上下文框，内部当前节点继续显示黄色 `#ffb800` 焦点框。
- 页面焦点与区域上下文视觉必须临时接管宿主节点的 `outline` 和 `box-shadow`，并在焦点移动、区域切换、关闭或销毁时精确恢复原值与 `!important` 优先级；宿主页面的蓝色焦点阴影不得与工具焦点框叠加成双重颜色。
- 状态配色继续通过现有主题变量定制，不新增任意 CSS 注入 API，不引入图标字体、图片或运行时依赖。
- 十字线继续由水平、垂直两条 `position: fixed` 的非交互实体线组成；默认危险色改为高饱和红 `#ff1f1f`，仍统一由 `toolbar.theme.danger` / `--a11y-danger` 覆盖，因此退出控制的默认危险色同步更新。
- 十字线必须完全移除 `box-shadow`、描边和外框，只保留纯色实体线；水平线高度和垂直线宽度均由 `2px` 提升为 `3px`。
- 十字线定位与鼠标跟随逻辑、`pointer-events: none`、`aria-hidden="true"` 以及工具栏状态图标保持不变。
- 工具栏 Shadow Host 的外部层级提升为常规 `z-index` 最大值 `2147483647`，内部 overlay 层级关系保持合理；常规站点内容不得覆盖工具栏，但原生 top layer（例如 `showModal()` 打开的对话框）不受普通 `z-index` 保证。
- 固定模式开启后，指针离开工具条实际区域必须立即收起，不再等待 `pinHideDelayMs`；指针移入视口顶部和现有展开触发继续按原行为展开，未固定模式的 pointerleave 不得触发收起。
- 固定状态下主模式与读屏专用模式使用完全相同的收起规则：切换进入读屏专用模式这一动作本身保持展开，之后 pointerleave 立即收起；reveal、视口顶部移入和 `Alt+Shift+A` 均在原模式内展开。未固定的读屏专用模式不得收起，区域控制、模式高度和页面占位不得回归。
- 鼠标触发立即收起时，即使焦点仍停留在“固定”或其他工具栏控件上也不得被 activeElement 守卫阻止；收起后必须在不改变页面滚动位置的前提下把该焦点安全转移到可见的展开控件，不能把焦点遗留在 `visibility: hidden` 的控件上。
- 纯键盘 `focusin` / `focusout` 继续使用现有展开与延迟收起语义，不得被鼠标立即收起路径改成无延迟；固定切换、12px 收起条以及 push/overlay 占位规则保持不变。
- 收起状态可以立即提交 Host 高度、12px 展开条、`pointer-events` 与焦点转移，但工具栏本体的 `visibility: hidden` 必须延迟到现有约 `180ms` 向上位移动画结束后再生效，不能截断离场动画。
- 展开时工具栏本体必须立即恢复 `visibility: visible`，再从收起位置按同一约 `180ms` 缓动进入；`prefers-reduced-motion: reduce` 下收起和展开均立即完成，不能保留 visibility 延迟或位移动画。
- 固定、自动收起、12px 展开条、默认 push 占位、overlay、全屏和其它功能业务逻辑保持现有行为。
- 闭合 Shadow Root、hostile CSS、严格 CSP 和 forced-colors 隔离能力不得退化。

## Acceptance Criteria

- [ ] 1200px 和 1440px 下主工具栏所有 13 个控制保持单行、无横向滚动条、无裁切，视觉尺寸与批准设计一致。
- [ ] 1200px 及以上时内层版心计算宽度不超过 1200px 且水平居中；1440px/1600px 下首尾内容不贴视口边缘，外层深色背景仍覆盖整个视口。
- [ ] 品牌轨道、控件组和连续轨迹线共用同一版心容器，不出现品牌贴左、控件单独居中或轨迹线横跨版心外的错位。
- [ ] 主模式与盲道导航模式的 Host、根节点和工具栏计算高度相同，切换模式时 body/offsetSelectors 的占位值不变化。
- [ ] 主模式控制顺序保持不变；盲道导航模式顺序严格为六类区域、朗读、帮助、读屏专用、退出。
- [ ] 盲道导航模式中的声音控制可见文案及 aria-label 使用“朗读”，功能仍复用 `readingEnabled`。
- [ ] 读屏专用控制在盲道导航模式中位于退出前，并在当前模式下显示与固定一致的开启高亮。
- [ ] 常态控制不再显示大面积浅色卡片；开启、退出、悬停和禁用状态各自可辨。
- [ ] 标准模式任一二态控制开启后保留原橙色卡片/图标，并在轨迹节点显示橙色外环及从中心展开的局部橙线；多个开启态可同时显示，关闭后对应局部橙线收回。
- [ ] 语速等非二态控制不显示橙色外环或局部轨迹，退出仍只使用红色危险状态，不误用橙色开启动画。
- [ ] 语速常态没有黄色边框；键盘 Tab/方向键聚焦任一控件时仍有清晰、非橙色的 `focus-visible` 提示。
- [ ] 点击、Enter 和空格均直接切换语速且焦点留在按钮；完整序列为 `0.75→1→1.25→1.5→0.75`，非预设值按“首个严格更大预设，否则 0.75”处理。
- [ ] Shadow DOM 中不存在语速 dialog、预设或滑块，语速按钮没有弹窗相关 ARIA；每次切换同步 state、持久化、`data-icon-state`、元信息、aria-label 和“当前语速 X 倍”提示，且不改变朗读开关。
- [ ] 连续轨道、节点和无文字分隔标记不会进入无障碍树，也不会改变按钮名称或事件目标。
- [ ] 成功定位区域后只有对应类别显示当前态；同类循环更新 `index + 1/count`，跨类定位移动当前态，失败定位、区域清除/失效、返回工具栏、关闭工具均不会留下错误高亮。
- [ ] 当前区域节点及其附近的局部轨迹为橙色，其余区域节点和轨迹仍为灰色；区域按钮本身不出现主功能开启态卡片，`focus-visible` 仍使用独立的非橙色高对比反馈。
- [ ] 当前节点具有清晰的“橙色实心节点 + 背景间隔 + 橙色外环”，与白色键盘焦点环可明确区分；局部轨迹从节点中心展开，跨类别时旧轨迹收起且新轨迹展开，清除时归零。
- [ ] 当前区域轨迹使用 `transform-origin: center` 与 `scaleX` 过渡，时长处于 `180–240ms`；减少动态效果模式下节点和轨迹的 transition 均为零。
- [ ] 点击区域控制、区域快捷键和页面焦点进入区域通过同一 `regionchange` 状态路径更新 UI，区域控制使用 `aria-current="location"` 而不是 `aria-pressed`。
- [ ] 普通 Tab 先到区域容器，下一次 Tab 再进入区域内第一个原生可聚焦节点，后续继续遵循 DOM 顺序；Shift+Tab 按相反顺序返回区域容器。
- [ ] 区域容器获得焦点时只有黄色焦点框；焦点进入内部节点后，外层区域保持 `#ff6c00` 高对比度橙色框，内部节点只有 `#ffb800` 黄色焦点框。
- [ ] 即使宿主节点使用蓝色 `outline` 或 `box-shadow`（包括 `!important`）表达焦点，工具开启期间也只显示工具拥有的单一焦点颜色，并在离开后精确恢复宿主样式。
- [ ] 1024px 下功能仍可操作，roving tabindex、自动滚入视图和退出工具均正常。
- [ ] pinned 收起/展开、默认 push/overlay 占位、滚动吸顶、状态恢复、重置和读屏模式切换回归通过。
- [ ] 默认主题下十字线与退出危险色均为 `#ff1f1f`；自定义 `toolbar.theme.danger` 后两者同步使用覆盖值。
- [ ] 十字线水平、垂直轴的计算尺寸均为 `3px`，`box-shadow: none`，无额外描边/外框，并继续保持 `position: fixed`、`pointer-events: none` 与 `aria-hidden="true"`。
- [ ] 工具栏 Shadow Host 的计算 `z-index` 为 `2147483647`；hostile CSS 及 Chrome/Edge 验证中常规页面内容无法覆盖工具栏，同时文档明确普通 `z-index` 不保证压过原生 top layer。
- [ ] 固定模式下 pointerleave 在明显短于配置延迟的时间内立即进入 12px 收起态；焦点若原在工具栏内则以 `preventScroll` 语义转移到可见的展开控件且页面滚动位置不变，按 Enter、现有快捷键或将鼠标移入视口顶部均可重新展开。
- [ ] 固定的读屏专用模式切换完成后保持展开，随后 pointerleave 使用同一 `180ms` 动画收起并保留六类区域控制、模式状态与等高布局；reveal、顶部移入和快捷键展开后仍停留在读屏专用模式。持久化的固定 + 读屏专用状态静默恢复后也按配置进入可收起状态。
- [ ] 未固定模式 pointerleave 不收起；纯键盘焦点离开固定工具栏时仍等待 `pinHideDelayMs` 后收起，并且固定前后的 push/overlay 页面占位不发生回归。
- [ ] 固定工具栏收起后的前约 `180ms` 仍为 `visibility: visible` 并完成向上 transform，动画结束后才变为 hidden；任一展开触发都立即恢复 visible 并缓动回位，减少动态效果模式下 visibility 与 transform 同步无动画切换。
- [ ] Chrome/Edge E2E、axe、hostile CSS、严格 CSP、forced-colors、单元测试、类型检查、Lint 和构建全部通过。

## Definition of Done

- 工具栏 DOM、SCSS、页面焦点/区域视觉所有权、状态/顺序测试、Chrome/Edge E2E 和运行契约同步。
- 视觉实现遵循批准稿，不修改 `public/index.html` 或两个用户 Logo。
- 不引入新运行时依赖、外部字体、图标资源或移动端布局。

## Technical Approach

- 在 `ToolbarUI` 中增加一个统一的版心容器，容纳非交互品牌轨道和两种模式的控件组；通过现有 `data-read-screen` 状态切换主模式/盲道导航文案。
- 调整 `buildScreenControls()` 的创建顺序，并把 `screenSound` 的显示名称改为“朗读”；动作 ID 和回调保持不变。
- 使用 SCSS Grid/Flex 的单行自适应轨迹布局：1200px 为舒适基准，1024px 使用紧凑回退；控制节点和分隔点优先使用伪元素，避免增加可聚焦 DOM。
- 通过统一 CSS 状态选择器覆盖 `aria-pressed`、危险操作、禁用、悬停和 `focus-visible`，不复制业务状态。
- 由现有 `regionchange` 事件把 `{ type, index, count }` 同步给 `ToolbarUI`；区域控制以 `aria-current="location"` / 数据属性渲染唯一当前类别和 `index + 1/count`，清除路径统一撤销该状态。
- 盲道模式的区域节点继续使用图标容器作为轨迹节点，并以伪元素渲染当前节点附近的局部橙色轨迹段；不得复用 `aria-pressed` 卡片样式。
- 所有区域控制都保留同一个局部轨迹伪元素，通过中心 `transform-origin` 和 `scaleX(0/1)` 切换状态；节点外环使用可过渡的阴影层形成背景间隔与橙色边界，减少动态效果媒体查询统一关闭过渡。
- 主模式保留控制 `::after` 作为现有轨迹节点，新增独立 `::before` 渲染局部短线；`aria-pressed="true"` 只切换该短线的中心缩放与节点外环，确保短线位于灰轨迹上方、节点下方且不改变单行布局。
- 页面占位继续读取统一的 `--a11y-toolbar-height`，两种模式不得覆盖该变量。
- 将默认 `toolbar.theme.danger` 更新为 `#ff1f1f`，十字线继续直接消费 `--a11y-danger`；SCSS 删除十字线阴影并将两轴厚度统一为 `3px`。
- 将 Shadow Host 外层 `z-index` 更新为 `2147483647`，不改变 Shadow DOM 内工具栏、浮层和视觉辅助元素的相对层级。
- 继续复用 `PageEffectsController` 的焦点与区域独立账本：区域上下文颜色保持 `#ff6c00`，两类账本在拥有节点期间都压制宿主 `box-shadow`，焦点账本覆盖同节点的区域账本，释放时按既有顺序恢复。
- 更新配置单测、工具栏/隔离 E2E 与运行契约，覆盖默认值、主题覆盖、纯色 `3px` 十字线、Host 计算层级及 Chrome/Edge hostile CSS 回归。
- 为 `ToolbarUI` 增加仅由 pointerleave 调用的立即收起路径：绕过延迟和工具栏内部 activeElement 拒绝条件，在需要时建立收起态并把焦点转移到 reveal；原 `scheduleCollapse()` 继续专用于打开、固定切换和键盘 focusout 的延迟语义。
- 移除 `ToolbarUI.updateState()`、`setCollapsed()`、`scheduleCollapse()`、pointerleave 路径及运行时打开/固定动作中把 `isReadScreen` 当作禁止收起条件的守卫；模式切换仍由既有 `isCollapsed: false` 提交保证当次保持展开，未固定状态等真实阻止条件保持不变。
- 删除 `ToolbarUI` 的语速面板 DOM、状态、事件与 `onRateChange` 回调；运行时处理 `speechRate` 动作时直接计算下一预设、提交状态并 announce，继续复用既有 `updateState()` 图标/元信息/aria-label 与偏好保存路径。
- 工具栏基础态声明 `visibility: visible`，并让 visibility 以零时长、零延迟恢复；collapsed 态继续使用 `180ms` transform，但把零时长 visibility 切换延迟 `180ms`。减少动态效果媒体查询继续以 `transition: none !important` 覆盖两者，使 hidden/visible 同步切换。

## Decision (ADR-lite)

**Context**：现有工具栏由等权白色卡片组成，视觉拥挤、缺乏层次，并在窄宽度出现明显横向滚动；双层设计又产生行数不对称和模式切换布局差异。

**Decision**：采用 1200px 桌面基准的单层“盲道轨迹”布局；主模式和盲道导航模式等高；状态通过表面、图标和轨道节点三重表达；盲道导航保留读屏专用控制并使用固定按钮同款高亮。

**Consequences**：产品获得独立识别度且模式切换不会推动页面；SCSS 布局和 E2E 覆盖会明显增加，但业务状态、公共 API、功能顺序及事件模型保持兼容。

## Out of Scope

- 不重新设计帮助页、大界面内容或页面演示站。
- 不开发移动端工具栏。
- 不修改盲道扫描分类、区域朗读文案、选项卡或语音服务逻辑；仅修正既有区域/页面焦点的顺序与视觉所有权。
- 不新增品牌配置 API、接入方自定义布局或任意图标上传。
