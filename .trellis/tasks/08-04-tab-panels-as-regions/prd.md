# 将选项面板纳入盲道视窗区

## Goal

让选项卡的每个关联面板同时具备盲道区域语义，例如“概览”选项对应“概览视窗区”、“属性协议”选项对应“属性协议视窗区”；面板可按盲道顺序定位，聚焦面板后仍可继续按 Tab 浏览内部控件。

## What I already know

- 标准选项通过 `role="tab"`、`aria-controls` 和面板 ID 建立关系，面板使用 `role="tabpanel"` 与 `aria-labelledby`。
- 当前 `RegionScanner` 的视窗区没有任何语义自动识别规则；只有显式配置或 `data-a11y-region="viewport"` 才能建立视窗区。
- 当前区域名称优先读取 `data-a11y-label`，再读取 `aria-labelledby`；因此面板若成为视窗区，可以自然从来源选项得到“概览”“属性协议”等名称。
- 可见区域容器会自动获得可逆的 `tabindex="0"`，Tab 会先到区域容器，再进入其原生可聚焦后代。
- `Alt+下方向键` 当前会聚焦面板并朗读标签面板专用说明；若面板同时成为区域，需要继续保证只朗读一条，不与区域进入提示重复。
- 隐藏面板使用 `data-a11y-hidden` 配合站点 CSS。用户已确认：显式配置为盲道区域的隐藏选项面板不能被区域导航排除，而应保留在对应分类的页面顺序中。
- `public/index.html` 当前包含用户未提交的大量演示内容与格式调整；实现时只能做局部增量，不能覆盖或重排其它内容。

## Confirmed Decisions

- 区域分类由接入方在每个面板上显式添加，例如 `data-a11y-region="viewport"`；工具不自动推测所有 `role="tabpanel"` 的分类。
- 面板无需重复维护 `data-a11y-label`，工具通过标准选项与面板关系识别来源选项名称，例如“概览”“属性协议”。
- 显式 `data-a11y-label` 仍保留最高名称优先级，供接入方确有需要时覆盖自动取得的选项名称。
- `regions.autoDetect: false` 不影响显式标记的面板区域。
- 显式标记的隐藏选项面板仍参与对应区域分类的计数和结构顺序。
- 通过 `Alt+Shift+区域数字` 或工具栏区域按钮导航到隐藏面板时，工具触发其来源选项已经配置的页面原事件，等待面板可见后再聚焦；工具不直接控制 `data-a11y-hidden`。
- 选项获得焦点时，选项提示中的区域分类继承其关联面板的显式区域分类，不再使用选项所在外层区域；选项本身不作为第二个盲道区域计数。

## Requirements (evolving)

- 每个由接入方显式添加合法区域分类、当前可见且结构有效的选项面板成为一个独立盲道区域。
- 演示页中普通、手动激活以及浮层/对话框示例的每个关联面板都显式配置区域分类；当前示例统一使用视窗区，朗读名称自动采用对应选项名称，例如“概览视窗区”。
- 面板区域进入 Tab 顺序后，下一次 Tab 按浏览器原顺序进入面板内部可聚焦节点。
- 显式标记的隐藏选项面板参与区域计数、快捷键导航和工具栏区域按钮循环，但在显示前不进入浏览器普通 Tab 顺序。
- 区域导航命中隐藏面板时，复用对应选项的激活模式与 `data-a11y-trigger-event`，触发页面原事件并同步选项状态；等待面板显示成功后再聚焦该区域。
- 页面事件未能在既有超时时间内显示目标面板时，不聚焦隐藏节点、不朗读进入成功，并给出明确失败提示。
- 面板切换使原面板隐藏后，它仍保留在区域顺序中；下一次循环可再次通过来源选项打开。
- 普通 Tab 聚焦面板、盲道快捷键聚焦面板及 Alt+下进入面板都不能产生重复朗读。
- Alt+下进入面板的分类名称取关联面板自身的显式区域分类，不再取选项所在外层区域；例如朗读“您已进入概览视窗区标签面板……”。
- 选项提示与面板提示使用同一分类，例如 `Tab，概览，视窗区，当前有浮动窗口……` 与“您已进入概览视窗区标签面板……”。
- 不在 `role="tab"` 上重复添加 `data-a11y-region`；否则选项和面板会成为两个独立区域并造成计数、区域快捷键顺序重复。
- 面板没有 `data-a11y-label` 时，通过有效的 `aria-labelledby` / `aria-controls` 关系使用来源选项名称；显式名称仍可覆盖。
- 没有显式区域分类的普通 `role="tabpanel"` 不加入盲道区域。

## Acceptance Criteria (evolving)

- [x] 普通、手动激活以及浮层/对话框示例中显式标为 `viewport` 的可见面板分别以对应选项名称成为视窗区，且不要求重复填写 `data-a11y-label`。
- [x] 面板容器可通过普通 Tab 和视窗区分类导航获得焦点。
- [x] 从面板容器继续 Tab 时进入内部链接、按钮或输入框，不制造静态内容焦点。
- [x] 选项切换后，当前可见和隐藏的显式面板都保留在视窗区计数与 DOM 顺序中；隐藏面板不直接进入普通 Tab 顺序。
- [x] 快捷键或工具栏区域按钮命中隐藏面板时，触发来源选项配置的页面原事件，面板显示后再聚焦并朗读对应区域。
- [x] 页面原事件未能打开隐藏面板时，焦点和当前区域不被错误切换，也不朗读成功提示。
- [x] Alt+下进入面板仍只朗读一次完整面板操作说明。
- [x] Alt+下的标签面板说明使用面板自身分类，能够得到“概览视窗区标签面板”等文案。
- [x] 选项焦点提示使用关联面板分类，能够得到“Tab，概览，视窗区……”，并与进入面板提示保持一致。
- [x] 选项不作为独立盲道区域重复计数；每个显式面板在分类数量和快捷键顺序中只出现一次。
- [x] 区域分类完全采用接入方在面板上的显式配置；显式区域名称可以覆盖自动取得的选项名称。
- [x] 没有显式区域分类的面板不加入盲道；`regions.autoDetect: false` 时显式面板区域仍正常工作。
- [x] 普通 DOM、open Shadow Root 和同源 iframe 的标准选项卡行为一致。
- [x] 单元测试、相关 E2E、类型检查、Lint 和构建通过。

## Definition of Done

- 代码、测试、README/属性协议和运行契约同步。
- 用户现有 `public/index.html` 内容只做必要局部修改或验证，不覆盖其它未提交改动。
- 所有工具添加的 `tabindex`、高亮和 ARIA 状态在隐藏、关闭或销毁时可逆恢复。

## Out of Scope (explicit)

- 不改变页面业务事件对面板显隐的所有权。
- 不直接添加或删除业务面板的 `data-a11y-hidden`；只触发来源选项已声明的原事件并同步现有 ARIA 状态。
- 不给面板内静态段落、标题或图片批量增加 `tabindex`。
- 不自动给所有 `role="tabpanel"` 写入或推测 `data-a11y-region`。
- 不给 `role="tab"` 重复添加区域属性，也不把选项作为与关联面板并列的第二个区域。
- 不把任意浮层或普通 `section` 自动识别为视窗区。
- 不新增另一套选项卡结构协议。

## Decision (ADR-lite)

**Context**：面板必须具备盲道区域能力，但不同站点可能把面板归为视窗区、正文区或其它分类，工具不能统一猜测；同时选项名称已经通过标准 ID 关系存在，不应要求接入方重复维护。

**Decision**：分类由接入方显式配置，名称由工具从关联选项自动解析。演示页只在面板上使用 `data-a11y-region="viewport"`，不重复添加 `data-a11y-label`，也不在选项上重复添加区域属性。隐藏的显式面板仍保留在区域序列中；区域导航命中它时，通过来源选项的原事件请求站点显示面板，显示成功后才完成区域聚焦。选项焦点提示通过选项与面板关系继承面板分类，保证选项和面板名称一致且区域只计数一次。

**Consequences**：分类可控且没有新配置项；接入方必须主动标记需要进入盲道的面板。区域扫描与导航需要区分“普通隐藏区域”和“可通过选项激活的隐藏面板区域”，区域切换由同步流程升级为等待页面显示结果的异步流程，并必须防止快速重复导航、过期激活和重复朗读。

## Technical Approach

- `RegionScanner` 继续按现有来源优先级解析分类。普通隐藏区域仍排除；只有具备显式合法分类、能够通过同一根节点内标准 `role="tab"` + `aria-controls` 关系找到来源选项的隐藏面板，才作为“可激活的隐藏区域”保留。
- `ScannedRegion` 增加内部的关联面板/来源选项元数据。名称仍先遵循 `data-a11y-label`、兼容名称和标准 ARIA 名称；缺少显式名称时，使用关联选项的可访问名称。
- 区域导航区分两组集合：计数和显式分类循环使用“可导航区域”（包含可激活隐藏面板），普通 Tab、焦点包含关系和自动恢复只使用当前可见区域，避免隐藏面板直接进入浏览器 Tab 顺序或被自动意外打开。
- `RegionNavigationController.navigate()` 在目标不可见且属于可激活面板时，通过异步回调请求 `TabsController` 显示面板；只有等待可见成功且请求仍有效时才设置当前区域、滚动、聚焦和朗读。失败或过期请求不更新位置与成功状态。
- `TabsController` 提供按面板查找来源选项并请求显示的内部能力，复用该选项的 `data-a11y-trigger-event`、配置回退、页面原事件和现有 `panelReadyTimeoutMs`，但不直接增删 `data-a11y-hidden`。
- 区域导航触发的“显示面板”和 Alt+下的“进入面板”使用独立的进行中状态，避免快速重复操作、过期完成和朗读互相抑制。
- Alt+下聚焦显式面板区域时，抑制通用区域容器的同步焦点播报，只保留标签面板专用说明；普通 Tab 或区域分类导航聚焦同一面板时仍使用完整区域进入提示。
- `formatPanelEntryAnnouncement` 与 `formatTabFocusAnnouncement` 都使用关联面板扫描到的区域分类；当面板没有显式区域时，自然省略分类，不回退到选项外层区域。
