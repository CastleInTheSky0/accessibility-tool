# 浏览器本地音色与发音人选择

## Goal

使用浏览器／操作系统通过 `speechSynthesis.getVoices()` 暴露的本地音色，为用户提供按语言筛选、选择、试听和保存偏好的能力，并在音色缺失、异步加载或页面语言变化时安全回退。

## Scope

- 正确处理初始空列表和 `voiceschanged` 异步事件。
- 按前一任务输出的规范化语言筛选和排序音色。
- 支持用户选择、试听、保存和清除音色偏好。
- 已保存音色不存在、语言不兼容或设备变化时安全回退。
- 页面目标语言变化时重新选择兼容音色。
- 保持 `SpeechController` 和 `BrowserSpeechAdapter` 为唯一语音请求链路。

## Non-goals

- 云端 TTS、厂商音色 ID、SDK、密钥和远程音频。
- 承诺跨浏览器、跨设备相同音色列表或相同音质。
- 在此任务内实现连续朗读、大字幕或移动布局。

## Technical Approach

- 新增本地 voice catalog／selection controller，集中处理获取、异步刷新、语言兼容和稳定标识匹配。
- 语音请求只携带已选择的本地 voice 语义，不建立第二套播放控制器。
- 偏好存储与语言偏好共享兼容的数据边界，旧 payload 继续有效。
- UI 入口必须在实施前完成桌面交互细化，避免破坏现有单行工具栏顺序和键盘模型。

## Acceptance Criteria

- [ ] `getVoices()` 初始为空时界面保持可用，并在 `voiceschanged` 后刷新。
- [ ] 音色按规范化语言筛选，用户可选择和试听。
- [ ] 用户偏好可保存；刷新或同源导航后恢复。
- [ ] 保存的音色不存在时回退到同语言默认音色，再回退浏览器默认行为。
- [ ] 页面语言变化后下一次朗读使用兼容音色。
- [ ] 无可用音色或不支持语音合成时保持现有不可用／回退行为。
- [ ] 不出现任何云厂商音色 ID、SDK、密钥或网络请求。

## Definition of Done

- 本地音色目录、选择、试听、持久化和回退均有自动化覆盖。
- 浏览器／设备差异和隐私边界有文档说明。
- 既有语速、朗读、事件、取消和自定义 adapter 不回归。
- 全部质量门禁通过并完成 Trellis 收尾。

## Unit Test Plan

- 空列表、同步列表、`voiceschanged`、重复音色和事件清理。
- 精确语言、主语言、默认 voice 和浏览器默认回退排序。
- 保存音色存在／缺失、设备列表变化和语言变化。
- 试听请求取消、过期回调和错误回退。

## E2E Test Plan

- 注入确定性 `speechSynthesis` voice fixture，验证异步加载、筛选、选择、试听和刷新恢复。
- Chrome／Edge 覆盖设置入口键盘操作、焦点返回和无音色情况。
- 断言不产生远程请求、不出现厂商配置。

## Documentation Update Plan

- 更新 README、API、兼容性和人工测试清单。
- 在运行时 contract 中记录 voice 标识、异步事件、回退和测试契约。

## Open Decisions for This Task

- 桌面端音色入口采用工具栏新控件、设置浮层还是复用既有控件的次级入口。
- 稳定偏好键优先使用 `voiceURI`、`name + lang` 组合还是分层匹配。
- 试听文案、最长时长和正在试听时再次选择的取消行为。

## Design/Implementation Gate

本任务在语言检测完成并归档后再细化完整 PRD；PRD 获确认前不实现生产代码。
