无障碍工具
使用说明

开始使用

  1. 在接入页面选择“打开无障碍工具”按钮。
  2. 工具栏打开后，使用左右方向键选择功能，按 Enter 或空格执行。
  3. 按 Tab 可离开工具栏并继续浏览页面内容。
  4. 选择“退出”会恢复页面原有视觉效果，并把焦点送回唤醒按钮。

主工具栏功能

朗读
开启后，聚焦、点击或悬停页面内容可朗读最小语义单元；新目标会打断旧语音。
语速
选择 0.75×、1×、1.25×、1.5× 预设，或使用 0.5×～2× 滑块。
配色
依次切换原始、白底黑字、黑底黄字、黄底黑字和蓝底白字。
放大 / 缩小
以 25% 为步长，在 75%～200% 之间调整页面，工具栏保持原尺寸。
大鼠标
使用约 48px 的高对比光标，并保留箭头、手型和文本光标语义。
十字线
鼠标操作时跟随指针，键盘操作时跟随当前焦点。
大界面
使用浏览器标准全屏。进入后可按 Esc 退出全屏。
固定
把工具栏固定在视口顶部；离开约 1.5 秒后自动收起为窄条。
重置
保持工具栏打开，恢复默认配色、100% 缩放、普通光标等设置。
帮助
在新标签页打开本说明。
读屏专用
切换到六类盲道区域导航界面。
退出
停止语音、退出全屏、撤销页面效果并关闭工具栏。

读屏专用模式

读屏专用界面按以下顺序显示：

  1. 视窗区
  2. 导航区
  3. 交互区
  4. 服务区
  5. 列表区
  6. 正文区
  7. 读屏专用
  8. 声音开关
  9. 帮助
  10. 退出

每类按钮显示当前数量。选择某一类后，会按页面结构顺序定位到下一个同类区域； 到末尾后回到第一个。不同分类分别记忆上次位置。

选项卡与关联面板

当焦点首次通过键盘进入标准选项卡组时，会提示“有关联内容面板，按 Alt+下方向键进入”。 进入面板后按 Esc 返回原选项。若面板是真正的浮动窗口，Esc 会先调用页面已有关闭方式。

  • Tab/Shift+Tab：按照页面顺序逐项聚焦选项，并在首尾自然离开选项卡组。
  • 横向选项卡：左右方向键移动，Home/End 到首尾。
  • 纵向选项卡：上下方向键移动，Home/End 到首尾。
  • 自动选项：通过 Tab 或方向键移动到该选项时触发页面原事件。
  • 手动选项：该选项获得焦点后，按 Enter 或空格触发页面原事件。
  • 面板视觉显示仍由页面原事件处理；工具只同步选项和面板的无障碍状态。

快捷键

快捷键作用
Alt + Shift + A展开已固定并收起的工具栏
Alt + Shift + 1下一个视窗区
Alt + Shift + 2下一个导航区
Alt + Shift + 3下一个交互区
Alt + Shift + 4下一个服务区
Alt + Shift + 5下一个列表区
Alt + Shift + 6下一个正文区
Alt + ↓从选项卡进入关联面板
Esc关闭语速面板、退出关联面板或退出浏览器全屏

六类区域快捷键只在读屏专用开启时生效，且不会拦截输入框、文本域或可编辑区域。

隐私与首版限制

工具默认不联网，不上传页面内容、朗读文本或用户操作。偏好仅保存在当前站点的 localStorage； 存储不可用时退化为当前页面内存。

v0.1.0 为桌面端版本，不包含移动端布局、连续朗读、大字幕、音色选择或云端语音服务。
