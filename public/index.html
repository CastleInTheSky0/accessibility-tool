02

Tabs and linked panels

原页面事件继续负责视觉切换

自动激活 / click

Tab、Shift+Tab 或方向键移动焦点时触发页面已有的 click 事件；工具只补充焦点与 ARIA 状态。

继续查看动态页面

推荐使用 data-a11y-region 与 data-a11y-label。

在选项上按 Alt + 下方向键进入面板；面板内按 Esc 返回原选项。

手动激活 / mouseover

方向键只移动焦点，按 Enter 或空格后触发 mouseover。

事件由示例站点处理，工具不直接改写面板显示样式。

关联浮层

模态演示

Tab 被约束在原生 dialog 内；按 Esc 后焦点回到“模态窗口”选项。

非模态浮层

焦点可以正常离开；按 Esc 使用页面已有关闭按钮并回到原选项。

registerTabs()

一次注册多个选项卡组

下方两个组件复用完全相同的 tab 与 panel 类名。工具按 DOM 顺序配对，并把不同直接父节点拆成彼此独立的 tablist；切换仍由本页已有 click 事件控制。

资讯栏目

要闻动态内容。第一组切换时，第二组的选中状态和面板保持不变。

返回区域协议

今日常山内容。到达此选项时，会触发本组页面已有的 click 事件。

政策栏目

政策文件内容。两个组件只调用一次 registerTabs()，各自首项独立选中。

政策解读内容。键盘导航、ARIA 状态和宿主事件都限制在当前选项卡组内。

const regions = AccessibilityTool.registerRegions([
  { target: '[data-js-region="viewport"]', region: 1, label: '入口' },
  { target: '[data-js-region="service"]', region: 4, label: '查询服务' },
  { target: contentElement, region: 6, label: '说明正文' }
]);

const tabs = AccessibilityTool.registerTabs([{
  tab: '.services-tab-hditem',
  panel: '.services-tabcut-bdcontent',
  region: 1
}]);

regions.dispose();
tabs.dispose();
